# Eventos INEMA em 30 segundos

Nove shorts verticais (9:16, 1080×1920, ~30 s) com o avatar e a voz do Nei Maldaner, um por área de assunto do
[eventos.inema.pro](https://eventos.inema.pro/): RSI, IA Cultivada, Claude → Codex, Codex + Claude, OSWork, JEV,
Gestão de IA, AGI-ready e WebMCP. Cada vídeo tem um gancho, uma tese com fatos da própria página da área e o convite:
os projetos e cursos são gratuitos em [inema.club](https://inema.club).

- Página com os nove players e o link de cada área: https://inematds.github.io/eventos-shorts/
- Os MP4 ficam na release [v1.0.0](https://github.com/inematds/eventos-shorts/releases/tag/v1.0.0) (`<area>.mp4`); o repo só tem a página.
- Produzidos com o [Explicavideos](https://inematds.github.io/explicavideos/guia/) (v2, modo 9:16): HeyGen Studio pela assinatura, Whisper local, HyperFrames.

Para trocar a origem dos vídeos, edite a constante `RELEASE_BASE` no topo do `index.html`.
